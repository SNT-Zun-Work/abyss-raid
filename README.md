# ABYSS RAID — AXOLOTL

A browser arcade shoot-'em-up boss fight against a giant mechanical axolotl.
Original fan-made game inspired by 90s arcade horizontal shooters. All graphics and music are
generated in code; no assets from any commercial game are used.

**Play:** open the GitHub Pages URL of this repository (desktop or phone in landscape).

| | Keyboard | Touch |
|---|---|---|
| Move | Arrow keys / WASD | Drag anywhere |
| Shot | G (Space) | Auto while touching |
| Abyss Burst | H | BURST button |
| Mute | M | — |

Version: v0.5.1
